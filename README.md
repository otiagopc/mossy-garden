# 🪴 Mossy Garden

só um diário de plantas pessoal. um aplicativo simples e orgânico que dá pra acompanhar o crescimento, regas e a saúde de cada planta do seu jardim.

## 🌿 o que o app faz?

* **estufa de plantas:** veja todas as suas plantas organizadas por cômodo ou confira o filtro especial de **sedentas** para saber quem precisa de água urgente.
* **diário individual:** cada planta tem seu próprio diário para você anotar o crescimento, folhas novas, troca de terra ou qualquer outro detalhe.
* **calendário de rega:** visualize de forma simples o calendário do mês com os dias em que cada planta foi ou precisa ser regada.
* **indicador de vitalidade:** acompanhe a saúde geral do seu jardim pela média de hidratação de todas as plantas direto no cabeçalho.
* **modo escuro:** alterne entre o tema claro e escuro para combinar com a iluminação do seu ambiente.
* **backup em json:** exporte todas as suas informações para um arquivo local ou importe seu backup de forma simples quando precisar.
* **pwa (offline):** o app funciona totalmente offline e pode ser instalado no seu celular ou computador como um aplicativo nativo.

## 🌱 tecnologias

* html5 & css
* javascript (puro)
* vercel (deploy da pagina)
